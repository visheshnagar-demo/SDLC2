# Project Features

## SCRUM-487 - Facultative Reinsurance Request Portal & Underwriter Review Queue

### Feature Summary
As an Insurance Carrier or Underwriter, I want a unified web portal to submit facultative reinsurance requests for Cyber and D&O risks and review/score submissions in an underwriter queue so that facultative requests can be processed quickly, accurately, and consistently.

### Key Features
- Carrier Submission Form for Cyber and D&O facultative reinsurance requests
- Underwriter Review Queue with automated risk scoring
- Missing Information Flagging engine
- Quote/Decline decision recording and notification workflow
