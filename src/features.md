# Project Features

## SCRUM-483 - CitiDirect Online Banking — Cash Statement Reports Module

### Feature Summary
CitiDirect Cash Statement Reports Module allows corporate treasury users and administrators to generate, manage, authorize, schedule, and export cash statement reports with dual-control maker-checker approval workflows.

### Key Features
- Maker-checker dual-control workflow for report authorization and approval
- Flexible cash statement report generation with custom filtering (date range, account, currency, entity)
- Multi-format exports supporting PDF, Excel (.xlsx), and CSV formats
- Automated report scheduling and delivery options (email, secure FTP/SFTP)
- Audit logging and status tracking for report requests and approvals
