# Project Features

## SCRUM-484 - CitiDirect Cash Statement Reports Module

### Feature Summary
As a Corporate Banking User / Treasury Manager, search, filter, generate, schedule, authorize, and export cash statement reports with maker-checker dual-control workflows across PDF, Excel, and CSV formats.

### Key Features
- Cash Statement Reports Landing Grid with status summary ribbon
- Report criteria form with advanced lookup modals (binocular lookup) and date selectors
- Schedule builder for recurring reports (daily, weekly, monthly)
- Delivery options management (email, SFTP, secure download)
- Maker-checker dual-control authorization workflow for pending actions
- Multi-format export: PDF (Citibank wordmark, KPI card, 9-column ledger), Excel, CSV
- Audit logging for all sensitive operations and RBAC security
