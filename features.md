# Project Features

## SCRUM-441 - Facultative Reinsurance Web Portal for Cyber & D&O Risks

### Feature Summary
Provides a web portal for insurance carriers to submit facultative reinsurance requests for Cyber and D&O risks, and equips underwriters with a review queue that automatically scores submission risks, highlights missing information, and tracks quote/decline decisions.

### Key Features
- Carrier submission portal supporting Cyber and D&O risk types
- Automated risk scoring engine (0-100 score & risk category)
- Automated missing information detection and flagging
- Underwriter review queue dashboard with sorting and filtering
- Quote and decline decision recording with formal notice generation
