# Project Features

## SCRUM-453 - Facultative Reinsurance Submission & Underwriting Portal

### Feature Summary
Enables ceding insurers to submit specialty line risks for facultative cover while providing reinsurance underwriters and managers with tools to review, score, quote, approve referrals, and track portfolio analytics.

### Key Features
- Submission Intake Form & Multi-LOB File Uploads
- Validation & LOB Completeness Checking
- Rules-Based Risk Scoring Engine (0-100)
- Underwriter Review Queue & Visual SLA Indicators
- Decision Workflow State Machine & Underwriting Manager Referrals
- Quote Builder (Share Offered, Ceding Commission, Reinsurance Premium)
- Immutable Audit Trail with User Attribution
- Underwriting Manager Portfolio Dashboard Analytics
