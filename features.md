# Project Features

## SCRUM-476 - Implement CitiDirect Cash Statement Reports: Account Statement – Comprehensive

### Feature Summary
As a CitiDirect user, I want to generate comprehensive account statements, so that I can view statement and transaction data across all my Citi accounts and registered third-party bank accounts, with various output formats and delivery options.

### Key Features
- Generate "Account Statement – Comprehensive" report with configurable criteria.
- Support for PDF, Excel (XLS/XLSX), CSV, DHTML, and RTF output formats.
- Delivery of reports via Citi Secure Email with maker-checker authorization.
- Scheduling of reports with various intervals and holiday options.
- Adherence to Citigroup ICGDS Lumen Theme for all UI components.
