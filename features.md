# Project Features

## SCRUM-380 - DG Cluster Assortment Advisor Single-Page Dashboard

### Feature Summary
Provides category managers with a single consolidated dashboard to make assortment decisions (add, keep, swap, remove) for Snacks products in Small Town Value Cluster stores.

### Key Features
- KPI Header Strip with 4 KPI cards (sales per linear ft, private brand %, in-stock rate, shelf capacity)
- SKU Performance Table with performance metrics and status badges (GROW/MAINTAIN/SWAP/REDUCE)
- Scenario Selector Cards with 3 options (Conservative, Balanced, Aggressive) and projected impact metrics
- Approval Review Panel displaying scenario summary, SKU action list, guardrail status checks, and Submit button
- Inline Confirmation displaying audit trail summary confirmation banner/modal within the same screen
