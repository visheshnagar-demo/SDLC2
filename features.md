# Project Features

## SCRUM-416 - DG Cluster Assortment Advisor — Single Consolidated Dashboard

### Feature Summary
A decision-support tool that helps Dollar General category managers decide which Snacks products to add, keep, swap, or remove in their Small Town Value Cluster stores — balancing sales performance, shelf space, and private brand goals.

### Key Features
- KPI Header Strip: Real-time summary cards for Sales per Linear Foot, Private Brand %, In-Stock Rate, and Shelf Capacity Utilization.
- SKU Performance Table: Detailed table listing Snacks SKUs with sales metrics, performance indicators, and action status badges (GROW, MAINTAIN, SWAP, REDUCE).
- Scenario Selector: Three side-by-side interactive cards (Conservative, Balanced, Aggressive), with Balanced pre-selected, dynamically driving projected impact calculations.
- Approval Review Panel: Inline summary displaying scenario selection, actionable SKU count breakdown, automated guardrail pass/fail status checks, and a Submit Approval trigger.
- Inline Confirmation & Audit Trail: Real-time success banner/modal on the same canvas presenting transaction reference ID, manager timestamp, selected scenario, and approved SKU action metrics.
