# Project Features

## SCRUM-431 - Instant Motor Insurance Premium Calculator Tool for Agents

### Feature Summary
A web-based tool for insurance agents to instantly calculate motor insurance premium quotes with detailed cost factor breakdowns and real-time input validation.

### Key Features
- Instant motor insurance premium calculation based on vehicle and driver inputs
- Itemized price factor breakdown showing individual price impacts
- Real-time validation for invalid inputs (e.g., negative car value, driver age under 16)
