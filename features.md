# Project Features

## SCRUM-454 - Gen Re QTB (Quote to Bind) Static Web Prototype

### Feature Summary
Allows underwriting specialists and reinsurance brokers to preview, simulate, and demonstrate reinsurance quoting, risk structuring, and policy binding workflows using realistic static synthetic datasets without needing live external core system integrations.

### Key Features
- Interactive Reinsurance Quoting Module
- Risk Structuring & Underwriting Dashboard
- Policy Binding Workflow Simulation
- Synthetic Reinsurance Dataset Ingestion & Mock Data Provider
