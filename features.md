# Project Features

## SCRUM-439 - Facultative Reinsurance Web Portal: Carrier Request Submission & Underwriter Scoring Review Queue

### Feature Summary
A web portal where insurance carriers submit facultative reinsurance requests for Cyber or D&O risks, and underwriters review, score, identify missing information, and record quote or decline decisions in a dedicated queue.

### Key Features
- Carrier Submission Web Interface for Cyber & D&O facultative reinsurance requests
- Automated Risk Scoring Engine to evaluate submissions based on risk profiles
- Automated Missing Information Detector to flag missing data fields and documentation
- Underwriter Review Queue & Dashboard displaying scored requests with filter and priority views
- Underwriting Decision Management to record Quote or Decline decisions with reasons and binding terms
