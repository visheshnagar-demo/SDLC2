# Project Features

## SCRUM-437 - Facultative Reinsurance Submission Portal and Underwriter Review Queue

### Feature Summary
A web portal enabling insurance carriers to submit facultative reinsurance requests for Cyber and D&O risks, paired with an underwriter review queue that scores submissions, detects missing information, and records quote/decline decisions.

### Key Features
- Carrier facultative reinsurance submission form supporting Cyber and D&O risk types
- Underwriter review queue displaying submissions with risk scores
- Automated missing information detection and alerting
- Quote/decline decision recording module with audit logging and decision reason capture
