# Project Features

## SCRUM-410 - DG Cluster Assortment Advisor Dashboard

### Feature Summary
A decision-support tool that helps Dollar General category managers decide which Snacks products to add, keep, swap, or remove in their Small Town Value Cluster stores — balancing sales performance, shelf space, and private brand goals.

### Key Features
- KPI header strip — a row of KPI cards: sales per linear ft, private brand %, in-stock rate, and shelf capacity.
- SKU performance section — a table of Snacks SKUs with their performance metrics and status badges (GROW / MAINTAIN / SWAP / REDUCE).
- Scenario selector — three side-by-side selectable option cards (Conservative / Balanced / Aggressive), each showing projected impact metrics; Balanced is pre-selected. Selecting a different option updates the review panel inline.
- Approval review panel — a summary of the currently selected scenario, the SKU action list, guardrail status checks, and a Submit button.
- Inline confirmation — after Submit, a success confirmation (inline banner or modal within the same screen) showing the audit-trail summary.
