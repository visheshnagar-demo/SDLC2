# Project Features

## SCRUM-463 - Facultative Reinsurance Submission & Underwriting Portal

### Feature Summary
An end-to-end portal allowing ceding insurers to submit specialty reinsurance risks and reinsurance underwriters/managers to evaluate, risk-score, quote, refer, or decline risks with audit trails and dashboard analytics.

### Key Features
- Ceding Company External Intake Form & File Uploads
- Validation & Completeness Engine
- Rules-Based Risk Scoring Engine
- Underwriter Review Queue & SLA Indicators
- Decision Workflow & Manager Referral
- Quote Builder
- Audit Trail & Compliance Logging
- Manager Executive Dashboard
