# Project Features

## SCRUM-312 - DG Cluster Assortment Advisor Dashboard for Small Town Value Cluster

### Feature Summary
Single consolidated dashboard screen for Dollar General category managers to evaluate, select, and submit product assortment scenarios for Small Town Value Cluster stores.

### Key Features
- KPI Header Strip: Top summary cards displaying Sales per Linear Foot ($), Private Brand %, In-Stock Rate %, and Shelf Capacity Utilization %.
- SKU Performance Table: Detailed interactive grid displaying Snacks SKUs with sales/margin metrics and dynamic status badges (GROW, MAINTAIN, SWAP, REDUCE).
- Scenario Selector Cards: Three side-by-side selectable cards (Conservative, Balanced, Aggressive) with projected impact metrics, pre-selecting Balanced by default.
- Approval Review Panel: Live dynamic panel summarizing active scenario details, SKU action counts, automated guardrail status checks, and a Submit action.
- Inline Confirmation & Audit Trail: Immediate inline banner or modal confirming successful submission with audit ID, timestamp, user ID, and scenario snapshot summary.
