# Project Features

## SCRUM-295 - DG Cluster Assortment Advisor Consolidated Dashboard

### Feature Summary
Provides Dollar General category managers with a single-screen dashboard to view KPI metrics, review SKU performance with GROW/MAINTAIN/SWAP/REDUCE badges, select assortment scenario options, perform guardrail checks, and submit approved assortment plans with an audit trail.

### Key Features
- KPI Header Strip featuring sales per linear ft, private brand %, in-stock rate, and shelf capacity
- SKU Performance Section displaying Snacks SKUs with performance metrics and status badges (GROW / MAINTAIN / SWAP / REDUCE)
- Scenario Selector with Conservative, Balanced (pre-selected), and Aggressive cards updating the review panel inline
- Approval Review Panel summarizing selected scenario, SKU action list, guardrail status checks, and a Submit button
- Inline Confirmation displaying audit-trail summary upon submission
