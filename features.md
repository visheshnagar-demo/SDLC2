# Project Features

## SCRUM-302 - DG Cluster Assortment Advisor - Single Page Consolidated Dashboard

### Feature Summary
A single-page consolidated decision-support dashboard for Dollar General category managers to evaluate and execute product placement decisions (add, keep, swap, remove) for Snacks products in Small Town Value Cluster stores.

### Key Features
- KPI Header Strip: Displays real-time aggregate store metrics including Sales per Linear Foot, Private Brand %, In-Stock Rate, and Shelf Capacity.
- SKU Performance Table: Interactive grid listing Snacks SKUs with performance metrics and color-coded status badges (GROW, MAINTAIN, SWAP, REDUCE).
- Interactive Scenario Selector: Three side-by-side scenario cards (Conservative, Balanced, Aggressive), with Balanced pre-selected by default.
- Approval Review Panel: Displays scenario impact summary, proposed SKU action list, guardrail compliance checks, and a Submit button.
- Inline Confirmation & Audit Trail: On submission, renders an in-page success confirmation modal or banner with audit-trail summary details.
