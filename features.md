# Project Features

## SCRUM-383 - DG Cluster Assortment Advisor Dashboard

### Feature Summary
A decision-support dashboard that helps Dollar General category managers decide which Snacks products to add, keep, swap, or remove in Small Town Value Cluster stores while balancing sales performance, shelf space, and private brand goals.

### Key Features
- Single Consolidated Canvas & Layout
- KPI Header Strip Cards
- SKU Performance Section & Action Status Badges
- Interactive Scenario Selector Cards
- Approval Review Panel & Guardrail Status Checks
- Inline Submission Confirmation & Audit Trail
