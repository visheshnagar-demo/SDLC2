# Project Features

## SCRUM-478 - CitiDirect Online Banking — Cash Statement Reports Module

### Feature Summary
As a Corporate Banking User / Operations Manager, I want to search, generate, schedule, manage delivery options, and authorize cash statement reports with maker-checker dual-control workflows, so that financial operations are streamlined, compliant, and auditable while supporting multiple export formats (PDF, Excel, CSV).

### Key Features
- Top navigation with mega-menu (Reports & Analytics, Self Service, File Services)
- Cash statement report search and filtering
- Report criteria form with advanced lookup and date selectors
- Schedule builder for recurring reports
- Delivery options management
- Maker-checker authorization workflow
- Export formats: PDF (with financial ledger layout), Excel, CSV
- Audit logging for all sensitive operations
