# Project Features

## SCRUM-464 - Gen Re Quote-to-Bind Static Web Application Prototype

### Feature Summary
An interactive, responsive static web prototype that showcases an end-to-end reinsurance Quote-to-Bind workflow with simulated AI agent orchestration and human-in-the-loop controls.

### Key Features
- End-to-End QTB Workflow Map & Dashboard (FR-01, FR-02) covering 12 lifecycle stages from Intake to Contract Handoff
- Submission Workspace & Extracted Data Review (FR-03, FR-04) with Document Intelligence Agent citations and confidence scores
- Completeness & Exception Center (FR-05) for handling missing data and exception workflows
- Underwriting Risk View & Pricing Studio (FR-06, FR-07) for risk analysis and actuarial pricing scenarios
- Portfolio & Capacity View, Quote Builder, and Approval Center (FR-08, FR-09, FR-10) for managing capacity limits, quote terms, and human-in-the-loop approval workflows
- Negotiation Comparison, Bind Readiness, and Bind Confirmation (FR-11, FR-12, FR-13) for audit-ready bind decisioning
- Agent Orchestration Console & Audit Traceability (FR-14, FR-15) for full visibility into agent reasoning, confidence scores, and action logs
- Executive Summary, Persona Switcher, and Predefined Demo Scenario Selector (FR-16, FR-17, FR-18) supporting Low-risk renewal, Incomplete submission, and High-exposure referral scenarios
